How It Works & Clean Uninstall

1. Installing from Catalog, GitHub Releases, or Local Files
Click Install on any catalog entry, paste any owner/repo into the GitHub Release bar, or drop a local .AppImage / .tar.gz / .tar.xz / .zip file. ahhhh automatically picks the matching Linux architecture asset, unpacks it under /opt/appimages/, links the binary in /usr/local/bin/, and registers a desktop launcher.
2. Common Linux AppImage Snags & GitHub Rate Limits
If an AppImage refuses to launch on newer distros, check FUSE support (fuse3 or libfuse2). If you check many GitHub repos frequently, set GITHUB_TOKEN in your environment to avoid unauthenticated API rate limits.
3. Removing Installed Apps
Click Remove on any installed app (or run ahhhh remove <name> in a terminal) to cleanly delete its files under /opt/appimages/, command symlink, icon, and menu entry.
