Clicky clicky FAQ FAQ

Ahhhh for idiots — no neckbeard jargon required
1. What actually happens when I click Install?
It grabs the latest .AppImage from GitHub, asks for your desktop password once, drops the file into /opt/appimages/, puts a terminal shortcut in /usr/local/bin/, pulls out the app's icon, and sticks it straight into your normal desktop app menu.
2. What's the yellow "DIY // LOCAL" box in the top-right?
Downloaded an .AppImage file from a random website that isn't in the store? Drop it onto that box (or click Pick File), optionally type a cleaner name, and hit Install. It gets the exact same menu icon and system setup.
3. Why does some app say "No GitHub link"?
The public AppImage catalog lists a few older apps that only link to a website instead of a direct GitHub release download. If you grab their .AppImage manually, just feed it into the top-right DIY // LOCAL box.
4. What's inside the Toy Crate?
Pure crate-digging fun. Clicking the Dice rolls 1–6 and deals out that many random floppies & cassettes from your current filter/category. Clicking Rummage tips a pile of disks across the table—click any one to inspect or install it.
5. How do updates and uninstalls work?
Click Check Updates to compare your installed GitHub apps against the latest releases—any outdated ones get a yellow Update button. Clicking Remove wipes the AppImage, command shortcut, icon, and menu entry cleanly.
6. Can I run this from the terminal without opening a browser?
Yep: ahhhh list, ahhhh install <name-or-file>, ahhhh update, and ahhhh remove <name> all work straight in your shell.
