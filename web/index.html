How It Works & Clean Uninstall

1. Installing an AppImage (Catalog or Local)
Click Install on a catalog app—or pick/drop a local .AppImage—and confirm the password prompt. ahhhh places the binary under /opt/appimages/, sets executable permissions, adds a command in /usr/local/bin/, and registers a desktop launcher.
2. Common Linux AppImage Snags
If an AppImage refuses to launch on newer distros, check FUSE support (fuse3 or libfuse2) or run it once in a terminal to see its output. If a catalog item is website-only, download its .AppImage manually and install it locally.
3. Removing Installed AppImages
Click Remove on any installed app (or run ahhhh remove <name> in a terminal) to remove its AppImage, shortcut, icon, and menu entry cleanly.
4. Removing ahhhh Itself
If installed via .deb: sudo apt remove ahhhh. If installed via install.sh: remove /usr/local/bin/ahhhh and ~/.local/share/applications/ahhhh.desktop.
